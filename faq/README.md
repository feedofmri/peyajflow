# PeyajFlow FAQ

The FAQ and sources page for the second QR code. It's a single static page (`index.html`) with its own copy of the icon, the Broadsheet stylesheet and the duotone Phosphor icon font, so it doesn't depend on the demo. It was generated from `PeyajFlow_FAQ_1.docx`; edit the HTML directly for text changes.

Run `scripts/package.sh` from the repo root to build `dist/peyajflow-faq.zip` for cPanel.
